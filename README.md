# Digital Clock ⏰

A stylish digital clock built using **HTML**, **CSS**, and **JavaScript**, featuring a glowing green display on a sleek black background. Inspired by retro-futuristic aesthetics and designed for real-time updates in a 12-hour format.

## 🌟 Features

- Real-time clock display
- 12-hour format with AM/PM indicator
- Leading zero formatting for hours, minutes, and seconds
- Neon green text with Orbitron font for a sci-fi vibe
- Centered layout using CSS transforms

## 🛠️ Tech Stack

- **HTML5** for structure  
- **CSS3** for styling and layout  
- **Vanilla JavaScript** for time logic and DOM updates

## 🧠 Logic Highlights

- Uses `Date()` object to fetch current time
- Formats time with leading zeros using ternary operators
- Updates every second using `setTimeout()`
